# 知识小农场

马原学习工作台。无需安装依赖，全部为静态文件，支持 GitHub Pages 子目录。

打开 https://pruitt-michaele.github.io/cixu-vocab/marx-farm/ 即可学习。

## 内容

- 两份PDF的226个原文单元，原文不可改写，来源页码可查。
- 106组具体共有命题，查看双份原文。
- 246道原文选择题，574张逐项回忆卡。回忆卡是自评，不计客观正确率。
- 每日计划、错题重考、间隔复习、逐日归档、收藏、备份导出及恢复。
- 仅朗读最先上传的《27马原肖1000精华知识点(7).pdf》原文；正常语速、短句续播、按原文章节选择、从头播放。一键晨听默认接着这份原文听，不加入生成题目或总结。
- 原创代码绘制的像素田园插画，未使用游戏素材。

## 保存与朗读

学习进度保存在当前浏览器的 localStorage，不自动同步到GitHub或其他设备。更换设备或清理浏览器前，在“成长手账”导出备份，新设备导入JSON。不要编辑备份里的内容ID。

朗读使用设备提供的中文语音。声音质量和离线能力取决于设备。Safari、Chrome、Edge通常可提供系统语音；未检测到中文声音时，页面会提示添加声音。锁屏和后台播放可能被浏览器中断，回来点击播放会从保存的短句继续。它不是定时唤醒手机的闹钟。

首次在线完整访问成功后，支持Service Worker的浏览器可缓存页面和知识库。语音服务是否离线可用取决于已安装的声音。不要在浏览器隐私模式里依赖长期保存。

## 在另一个仓库发布

将本目录内容上传到仓库根目录，或一个独立子目录。仓库 Settings → Pages → 选择对应分支与发布目录，保存后等待发布。所有资源都是相对路径，仓库名不影响使用。无需构建，也无需配置任何密钥。

## 文件

index.html 为页面，style.css 为样式，app.js 为交互，core.js 为复习与归档逻辑，data.js 为全量原文与练习，sw.js 为离线缓存，assets/farm.svg 为原创田园插画。

原文与整理元数据分开。资料中存在12项待核对或差异提示；原句保留，争议命题不拿来自动判分。没有宣称这些练习就是肖1000的原题。
